En el Readme, explica cómo desarrollarías una pequeña aplicación o juego.

01- Quiero crear una aplicación, esta aplicación será un juego llamado Driftso.

Este juego constará de coches, habrá diferentes tipos de vehiculos a elegir como: Motocicletas, Camiones, turismos y Furgonetas.

- Una motocicleta con 50 de vida y 150km/H de velocidad máxima.
- Un camión con 200 de vida y 80km/h de velocidad máxima.
- Un turismo con 80 de vida y 120km/h de velocidad máxima
- Una furgoneta con 100 de vida y 100km/h de velocidad máxima.


- También quiero que haya diferentes mapas como:
- Desierto
- Selva
- Playa



  02- La plataforma para desarrollar el videojuego sería Visual Studio ya que creo que es la más visual y practica, los lenguajes utilizados serían HTML y JAVA.

  - El algoritmo seria la cantidad de vueltas que daría cada coche, que en este caso el que llega primero a 3 vueltas saldria una pantalla de "VICTORIA"


  03- Cuando el jugador abra Driftso  el juego se iniciará y aparecerá un menú para elegir un vehículo y un mapa. Una vez hecho esto empezará la carrera, el programa irá leyendo las acciones del jugador, moviendo el vehículo y contando las vueltas hasta que se llegue a 5 vueltas, termine la partida y se muestre el ganador.
